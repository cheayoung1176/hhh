# Aether Doc AI — MVP (기능명세서 Rev.3 기준)

## 검증하려는 가설
"PDF를 올리면 요약·목차·키워드를 바로 보고, 질문하면 출처 페이지와 함께 답을 받는다"는 핵심 루프가 사용자에게 유용한가.

## MVP 범위 (Rev.3 기능 매핑)
| 기능 | MVP 구현 |
|---|---|
| F-03 PDF 업로드 | .pdf만 허용, 50MB 초과 시 안내 모달 (실제 파일 검증) |
| F-05 상태 인디케이터 | 진행(스피너) / 완료(체크) / 실패(경고) 3종, 색상+아이콘 |
| F-05-1 접근 제어 | 진행 중: 토스트, 실패: [재분석 시도]/[문서 삭제] 모달 |
| F-06 정렬 | 최신순 / 이름순 / 용량순 |
| F-06-1 삭제 | 2차 확인 모달 (스와이프·이름변경은 MVP 제외) |
| F-08 스트리밍 답변 | 토큰 단위 출력 시뮬레이션 (SSE 대신 클라이언트 재생) |
| F-09 출처 확인 | 출처 칩 → 모바일 바텀 시트(60%) / 데스크톱 Split View, #FFF176 하이라이트 |
| F-10 서브탭 | 요약 / 목차(페이지 이동) / 키워드 |
| F-11 키워드 칩 | 칩 선택 시 질의 자동 전송 |
| F-02-2 입력 보안 | 모든 사용자 입력 HTML Escape 후 렌더링 |
| 반응형 | 모바일 단일 화면 / 900px 이상 2단 Split View, 전환 시 상태 유지 |

## 의도적으로 제외한 것
로그인(F-01, F-01-1), 실제 PDF 파싱·AI 호출, 대화 히스토리(F-12), 스와이프, Phase 1~3 제안 기능.
업로드한 파일도 **샘플 분석 결과**를 보여주며 화면에 안내 문구가 표시된다. 질문은 미리 준비한 답변과 키워드로 매칭하고, 매칭 실패 시 "문서 내 명확한 근거를 찾지 못했습니다"를 표시한다.

## Vercel 배포 (정적 사이트)
1. GitHub에 새 저장소를 만들고 `index.html`을 올린다.
2. vercel.com → Add New → Project → 저장소 선택 → Framework Preset: Other → Deploy.
   (또는 `npx vercel --prod` 를 이 폴더에서 실행)
3. 발급된 `https://....vercel.app` 주소를 제출한다.
